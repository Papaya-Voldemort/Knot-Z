A collaborative, browser-based WebOS. This repository currently establishes its TypeScript workspace and subsystem boundaries; it does not yet implement the OS.

## Layout

- `apps/` — deployable browser applications; `desktop` is the WebOS entry point.
- `built-in-apps/` — applications bundled with the OS, each with its own manifest.
- `system/` — kernel, shell, virtual filesystem, package manager, and settings internals.
- `sdk/` — stable public contracts and UI primitives for applications.
- `services/` — intentionally empty foundations for future cloud services.
- `docs/` — architecture, SDK, and protocol documentation.
- `tooling/` — local development and build helpers.

## Dependency boundaries

Applications use `@webos/app-api` and public `@webos/types` contracts. The SDK is the public boundary; the kernel coordinates system services, and system packages keep their implementation details private. In particular, applications must not import files from `system/*/src`.

```text
Apps → SDK → Kernel → system services
```

The package manager will discover bundled applications from their adjacent `manifest.json` files in v1. A future registry can supply the same package/manifest shape remotely, without creating a shared app registry.

## Collaboration

Subsystems own their folders and package manifests. Prefer adding focused packages, manifests, and documents over changing shared configuration. Keep public APIs explicit, small, and dependency directions one-way so teammates can safely commit directly to `main`.
